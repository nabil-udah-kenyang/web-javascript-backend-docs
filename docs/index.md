## Mulai dengan konteks yang tepat

Roadmap ini sengaja berfokus pada fondasi bahasa untuk backend Node.js. HTML, CSS, frontend framework, database, ORM, autentikasi, dan deployment tidak diulang di sini.

<div class="note-grid">
  <div class="note-card">
    <strong>Fokus utama</strong>
    <p>JavaScript modern, cara kerja runtime, module, asynchronous code, dan TypeScript.</p>
  </div>
  <div class="note-card">
    <strong>Gaya belajar</strong>
    <p>Baca konsep singkat, jalankan contoh, ubah kodenya, lalu kerjakan latihan bab.</p>
  </div>
  <div class="note-card">
    <strong>Target akhir</strong>

  </div>

## Jalur yang akan ditempuh

```text
01 Fundamental JS → 02 Function & scope → 03 Module
       ↓                    ↓                ↓
04 Async JS → 05 Node.js → 06 TS Fundamental → 07 TS Backend → 08 Project
```

::: tip Cara terbaik memakai catatan ini
Jangan menyalin contoh begitu saja. Ketik ulang, buat error kecil dengan sengaja, lalu jelaskan kembali dengan kata-katamu sendiri. Pemahaman mulai terasa ketika kamu bisa memprediksi output sebelum menjalankan program.
:::
