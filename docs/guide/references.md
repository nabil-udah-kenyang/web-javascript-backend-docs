# Referensi pilihan

Catatan di handbook ini diringkas agar enak dibaca berurutan. Saat ingin memperdalam detail edge case atau API, gunakan sumber primer berikut.

## JavaScript

- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) — referensi bahasa dan API bawaan.
- [JavaScript.info](https://javascript.info/) — penjelasan bertahap dengan banyak contoh.
- [MDN JavaScript Modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) — module ESM.
- [MDN Promise](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — API Promise dan combinator.
- [MDN Event Loop](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Event_loop) — gambaran eksekusi asynchronous.

## Node.js

- [Node.js Learn](https://nodejs.org/learn) — materi pengantar runtime.
- [Node.js API Documentation](https://nodejs.org/api/) — dokumentasi `fs`, `path`, `process`, dan API bawaan lain.
- [Node.js ECMAScript Modules](https://nodejs.org/api/esm.html) — perilaku ESM di Node.js.

## TypeScript

- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) — rujukan utama bahasa TypeScript.
- [TypeScript for JavaScript Programmers](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html) — jembatan dari JS ke TS.
- [TypeScript Playground](https://www.typescriptlang.org/play) — mencoba snippet tanpa setup lokal.
- [TSConfig Reference](https://www.typescriptlang.org/tsconfig/) — penjelasan konfigurasi compiler.
- [TypeScript Modules](https://www.typescriptlang.org/docs/handbook/modules/introduction.html) — module dan output TypeScript.
- [DefinitelyTyped](https://github.com/DefinitelyTyped/DefinitelyTyped) — type declaration untuk package yang belum menyediakan type.

::: tip Cara membaca dokumentasi
Mulai dari contoh paling kecil, cari tipe input dan output, lalu periksa bagian “Exceptions”, “Notes”, atau “Compatibility”. Dokumentasi bukan hanya tempat mencari syntax; ia juga menjelaskan batasan API.
:::
