ROADMAP BELAJAR JAVASCRIPT & TYPESCRIPT
FOKUS: FUNDAMENTAL BAHASA UNTUK BACKEND NODE.JS & EXPRESS

TUJUAN UTAMA
Memahami JavaScript dan TypeScript dengan kuat sebelum menggunakannya untuk membangun backend menggunakan Node.js dan Express.

Fokus roadmap ini adalah fundamental bahasa, cara kerja JavaScript, pengelolaan data, function, module, asynchronous programming, serta sistem tipe TypeScript.

KONSEP DATABASE, SQL, RELASI, MIGRATION, ORM, DAN CRUD DATABASE TIDAK DIBAHAS ULANG karena sudah dipelajari melalui PHP dan Laravel.

==================================================
BATASAN DAN ARAH BELAJAR
==================================================

FOKUS:
- JavaScript modern (ES6+).
- Fundamental bahasa yang sering digunakan dalam backend.
- Asynchronous JavaScript dan event loop.
- Module system.
- TypeScript fundamental hingga intermediate.
- TypeScript untuk function, object, data, dan asynchronous code.
- Memahami bagaimana JavaScript/TypeScript dijalankan oleh Node.js.

TIDAK MENJADI FOKUS:
- HTML, CSS, DOM, dan manipulasi browser.
- React, Vue, Angular, dan framework frontend.
- Tailwind CSS.
- SQL dan desain database.
- ORM seperti Prisma atau Sequelize.
- Migration, relasi tabel, dan query database.
- Materi Express secara mendalam.
- Authentication dan deployment.

Catatan:
Materi HTTP, JSON, fetch, environment variable, dan Node.js hanya disentuh ketika diperlukan untuk memahami penggunaan JavaScript/TypeScript di lingkungan backend.

MULAI BELAJAR NODE.JS DAN EXPRESS

==================================================
PRINSIP BELAJAR
==================================================

1. Jangan menghafal syntax tanpa memahami cara kerjanya.
2. Utamakan memahami JavaScript sebelum masuk TypeScript.
3. Jangan terburu-buru menggunakan TypeScript jika konsep JavaScript belum kuat.
4. Biasakan membaca dokumentasi resmi.
5. Praktikkan setiap materi dengan kode kecil.
6. Pahami array dan object dengan baik karena sangat sering digunakan untuk mengolah data.
7. Beri perhatian khusus pada function, scope, closure, dan asynchronous programming.
8. Pahami Promise dan async/await, jangan hanya menyalin syntax.
9. Biasakan menggunakan module agar kode tidak menumpuk dalam satu file.
10. Gunakan TypeScript strict mode ketika sudah mulai praktik TypeScript.
11. Hindari any jika tipe yang lebih aman bisa digunakan.
12. Ingat bahwa TypeScript hanya memeriksa tipe saat development/compile-time; validasi data dari luar tetap diperlukan saat runtime.
13. Tidak perlu mengulang materi database dan ORM yang sudah dikuasai.
14. Jangan masuk ke banyak framework sebelum fundamental bahasa benar-benar dipahami.

==================================================
TARGET AKHIR
==================================================

Setelah menyelesaikan roadmap ini, diharapkan mampu:

- Menulis JavaScript modern tanpa bergantung pada framework.
- Memahami cara kerja function, object, scope, closure, dan class.
- Mengolah array dan object dengan berbagai method.
- Memahami module system dan pengorganisasian kode.
- Menguasai Promise, async/await, dan asynchronous programming.
- Memahami dasar event loop dan runtime Node.js.
- Menulis TypeScript dengan type yang tepat.
- Menggunakan union, narrowing, generic, dan utility types.
- Memahami konfigurasi TypeScript untuk Node.js.
- Memahami perbedaan static type checking dan runtime validation.
- Membaca serta memahami kode TypeScript yang digunakan dalam project backend.

JALUR BERIKUTNYA:
Setelah roadmap ini selesai, lanjutkan ke Node.js Fundamental dan Express.js menggunakan TypeScript.

Catatan akhir:
Roadmap ini sengaja tidak memasukkan pembelajaran SQL, PostgreSQL, ORM, migration, dan konsep relasi database. Pengetahuan yang sudah diperoleh melalui PHP dan Laravel dapat langsung digunakan kembali ketika nanti membangun backend dengan Node.js dan Express.
